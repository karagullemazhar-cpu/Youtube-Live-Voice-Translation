Youtube Live Voice Translation Gizlilik Politikası

Youtube Live Voice Translation, yalnızca kullanıcının açıkça seçtiği sekmenin sesini gerçek zamanlı çevirmek için çalışır. Uzantı bağımsız bir üçüncü taraf ürünüdür; Google veya Alibaba tarafından geliştirilmiş, desteklenmiş ya da onaylanmış değildir.

Tek amaç

Uzantının tek amacı, kullanıcının açıkça seçtiği aktif sekmenin sesini kullanıcının seçtiği Gemini Live veya Qwen LiveTranslate uyumlu API hizmetiyle gerçek zamanlı çevirmek; çevrilmiş sesi ve transkriptleri kullanıcıya göstermektir. Uzantı reklam, analiz, gezinme takibi, sayfa içeriği toplama veya bu amaç dışında bir özellik çalıştırmaz.

İşlenen veriler

  • Çeviri başlatıldığında seçili sekmeden yakalanan ses.
  • Seçili sağlayıcının ürettiği orijinal ve çevrilmiş transkriptler.
  • Kullanıcının girdiği Gemini veya Qwen API anahtarı.
  • Kaynak/hedef dil, model ve ses seviyesi gibi uzantı tercihleri.
  • Yalnızca yakalanabilir bir sayfa olduğunu doğrulamak için aktif sekmenin URL şeması.

Verilerin kullanım amacı ve paylaşımı

Kullanıcı “Kabul et ve başlat” düğmesine bastığında sekme sesi ve çeviri transkriptleri yalnızca seçilen çeviri hizmetinin sağlanması amacıyla doğrudan ilgili API hizmetine gönderilir:

  • Sabit resmî Google Gemini Live API endpointi, kullanıcı Gemini modelini seçtiğinde.
  • Sabit Alibaba Cloud Model Studio Singapur Qwen LiveTranslate API endpointi, kullanıcı Qwen modelini seçtiğinde.

API anahtarı yalnızca seçilen sağlayıcıda kimlik doğrulaması yapmak için kullanılır. Uzantı geliştiricisinin işlettiği bir sunucuya ses, transkript, API anahtarı veya gezinme verisi gönderilmez. Veriler reklam, profilleme, kredi değerlendirmesi veya satış amacıyla kullanılmaz ve reklam ağları ya da veri brokerlarıyla paylaşılmaz.

Saklama ve güvenlik

  • Gemini ve Qwen API anahtarları chrome.storage.local içinde, yalnız güvenilir uzantı bağlamlarının erişebileceği şekilde bu cihazda saklanır.
  • API anahtarları kullanıcı değiştirene, “Tüm yerel ayarları ve oturum verilerini sil” düğmesine basana veya uzantıyı kaldırana kadar korunur.
  • Transkriptler ve çalışma durumu yalnızca chrome.storage.session içinde tutulur ve tarayıcı yeniden başlatıldığında silinir.
  • Ham ses uzantı tarafından diske kaydedilmez.
  • Kaynak/hedef dil, model ve ses seviyeleri gibi tercihler yerel uzantı depolamasında tutulur.
  • API bağlantıları WSS/TLS ile şifrelenir. Chrome bağlantı iznini kullanıcı başlattığında Gemini için yalnız Google API alanı, Qwen için yalnız sabit Alibaba Cloud Singapur API alanı adına ister.

Kullanıcı kontrolü ve silme

Ses aktarımı yalnızca kullanıcı her başlatma öncesinde görünür veri açıklamasını kabul edip düğmeye bastığında başlar. “Durdur” düğmesi ses yakalamayı ve sağlayıcı bağlantısını kapatır. “Tüm yerel ayarları ve oturum verilerini sil” düğmesi API anahtarlarını, transkriptleri, çalışma durumunu ve tercihleri temizler. Uzantının kaldırılması da uzantıya ait yerel verileri siler.

Chrome izinlerinin gerekçeleri

  • tabCapture: Yalnız kullanıcı başlattığında seçili sekmenin sesini çeviri için yakalamak.
  • activeTab: Kullanıcının seçtiği aktif sekmeyi belirlemek ve sekmenin yakalanabilir bir HTTP/HTTPS sayfası olduğunu doğrulamak.
  • offscreen: Popup kapandıktan sonra Web Audio işlemesini, sağlayıcı WebSocket bağlantısını ve çevrilmiş ses oynatmayı sürdürmek.
  • storage: Tercihleri ve API anahtarlarını güvenilir uzantı bağlamlarıyla sınırlı cihaz depolamasında; transkriptleri ve çalışma durumunu yalnız tarayıcı oturumunda saklamak.
  • declarativeNetRequestWithHostAccess: Qwen seçildiğinde Bearer kimlik doğrulama başlığını yalnız uzantının başlattığı, kullanıcının izin verdiği Qwen WebSocket bağlantısına eklemek.
  • Opsiyonel sabit host kapsamları: Yalnız generativelanguage.googleapis.com ve dashscope-intl.aliyuncs.com için bağlantı izni istemek. Bu izinler kurulum sırasında verilmez; kullanıcı ilgili modeli başlattığında yalnız o sağlayıcının alan adı için istenir.

Uzantı içerik betiği kullanmaz, ziyaret edilen sayfanın metnini veya DOM içeriğini okumaz ve izinleri arka planda kendiliğinden istemez. Sekme sesi aktarımı yalnız kullanıcının görünür veri açıklamasını kabul ederek başlattığı çeviri oturumunda gerçekleşir.

Üçüncü taraf koşulları

Google veya Alibaba, kendi hizmetinde aldığı verileri kendi gizlilik, saklama, güvenlik, kota ve ücretlendirme koşullarına göre işleyebilir. Kullanıcı ilgili hizmetin koşullarını incelemelidir:

  • Google Gizlilik Politikası
  • Alibaba Cloud Gizlilik Politikası

Limited Use beyanı

Google API’lerinden alınan bilgilerin kullanımı, Limited Use gereklilikleri dâhil olmak üzere Chrome Web Store Kullanıcı Verileri Politikası’na uygun olacaktır. Uzantı yalnızca açıklanan tek amacı olan gerçek zamanlı sekme sesi çevirisini sağlamak için gerekli verileri işler.

Paket ve kod güvenliği

Çalıştırılabilir JavaScript kodunun tamamı uzantı paketinin içindedir. Uzantı uzak sunuculardan JavaScript veya WebAssembly indirip çalıştırmaz; çeviri API’lerinden yalnız çeviri oturumu için gereken ses, metin ve durum verilerini alır.

İletişim ve değişiklikler

Gizlilik soruları için Chrome Web Store listelemesindeki geliştirici iletişim veya Destek kanalı kullanılabilir. Veri işleme uygulamaları değişirse politika ve uzantı içi açıklama, yeni uygulama başlamadan önce güncellenir.
